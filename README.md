# 固定費チェッカー

家電の電気代・サブスクの合計・毎月の固定費をまとめてチェックできる無料のWebアプリ(PWA)。

**アプリ本体: https://gryo1240.github.io/koteihi/**

- **家電の電気代を即計算**: エアコン・こたつ・ドライヤーなど約30種の家電プリセット(タップで反映)。1時間/1日/1ヶ月/1年の電気代と「つけっぱなしなら月いくら」を表示。単価は全国目安31円/kWhから変更可
- **サブスクの棚卸し**: Netflix・Amazonプライムなど18種のプリセット+手入力。年払いも月換算して合計。使用頻度を「よく使う/たまに/ほぼ使ってない」で記録すると、解約した場合に**年いくら浮くか**を自動計算
- **固定費まるごと診断**: 家賃・光熱費・スマホ・保険などを入力すると月/年の合計。手取り月収を入れると固定費比率をゲージ表示(目安45%以下)
- **見直しポイントの自動提案**: 入力データから「スマホ代が高い」「使っていないサブスクがある」などを検出し、浮く金額とともに提示。あわせて節約の考え方をまとめた知識記事5本を収録
- データはすべて端末内(localStorage)にのみ保存。外部送信・同期機能なし

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体(HTML/CSS/JSすべて1ファイル) |
| `manifest.webmanifest` / `sw.js` | PWA化(インストール・オフライン対応) |
| `icon-*.png` / `apple-touch-icon.png` | アプリアイコン |
| `docs/screenshot-*.png` | 紹介用スクリーンショット |

`main` ブランチに push すると GitHub Pages に自動デプロイされます。

ブログ等での紹介記事を書く場合は [HANDOVER.md](HANDOVER.md) を参照してください。
